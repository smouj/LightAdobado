## Current release status

There is no tested LightAdobado installation package yet. The source build is still being checked,
so the older LightCraft package names and release instructions do not describe a current
LightAdobado download.

Check [LightAdobado releases](https://github.com/smouj/LightAdobado/releases). Install a package
only when its release notes identify it as a tested LightAdobado build with the current app icon.

## Build from source

The [LightAdobado repository](https://github.com/smouj/LightAdobado) contains the source and build
instructions. Source builds are for developers until a package has been installed and tested on
the target system.

## Get help

For installation problems, open an issue in the [LightAdobado tracker](https://github.com/smouj/LightAdobado/issues).
Include your operating system, the commit or package you used, and the exact error. Do not attach
private photo libraries or originals.
